# Hackathon backlog — reference

An example of the finished backlog (invented data, in the shape `export.py` writes) and its `plan.md`: three
epics, nine stories with acceptance criteria, five MVP stories estimated at 15 points against a capacity of
16, and the rest labelled `later`. The map story was split from the list of drop-off points so the list could
ship first. `customfield_10016` is only an example id — story-point field ids differ between Jira sites, which
is why the check finds the field through the export's `names`.
